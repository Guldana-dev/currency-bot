# Currency Bot 💱

A Telegram bot for converting currencies to Kazakhstani tenge (KZT).

## Features

- Currency selection through Telegram buttons
- Enter an amount to convert
- Currency conversion to KZT
- Support for multiple currencies (planned)

## Technologies

- Python
- Telegram Bot API
- Git and GitHub

## Getting Started

1. Install Python.
2. Install the dependencies listed in `requirements.txt`, if available.
3. Configure your Telegram bot token using an environment variable.
4. Run the bot using the project's Python entry point.

## Security

Never publish your Telegram bot token or other secrets in the repository.
